# Global Terrorism Analysis Dashboard

## Project Overview

The Global Terrorism Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI. It explores global terrorism incidents through historical, geographical, and analytical perspectives.

The project aims to transform raw terrorism data into meaningful insights using interactive dashboards and data visualization techniques.

## Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning and Transformation
- Data Visualization
- Exploratory Data Analysis (EDA)

## Dataset

The project uses the Global Terrorism Database (GTD), containing historical information about terrorist incidents across different countries and regions.

Key dataset attributes include:

- Year and date of attack
- Country and region
- City and geographical coordinates
- Attack type
- Target type
- Terrorist group
- Number of fatalities
- Number of injuries
- Weapon type

**Dataset source:** [Global Terrorism Database – START](https://www.start.umd.edu/gtd/)

## Dashboard Pages

The Power BI report contains four interactive pages:

1. **Overview** – High-level view of global terrorism incidents.
2. **Dynamics** – Historical patterns and changes in terrorism activities.
3. **Geography** – Geographical distribution of terrorist incidents.
4. **Summary** – Consolidated analytical overview.

## Project Objectives

- Analyze historical terrorism incident data.
- Explore geographical patterns across countries and regions.
- Understand attack types and target categories.
- Examine casualties and incident trends.
- Present findings through interactive Power BI visualizations.
